# esquemes v2 · versiones descargables

Ejecutables de la app de esquemas de red para Windows 11. Solo hay binarios: el código está en un repo privado.

- **Descargar:** en [Releases](../../releases/latest), `PruebaTauri.exe`.
- **Primera vez:** Windows avisa porque el .exe no está firmado → «Más información» → «Ejecutar de todas formas».
- **Actualizar:** desde la propia app, con el botón «Buscar actualización».

Cada versión la publica la compilación automática; aquí solo se guardan las cinco últimas.
